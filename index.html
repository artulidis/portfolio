AK Streaming

AK Streaming demonstrates the use of REST API’s to enable communication between a React front end and a Django back end. Requests are initially directed to a well-organized Nginx server, from which they are redirected to either an individual application server - Daphne, or to static file locations. Celery triggers asynchronous tasks, which employ Ffmpeg in streaming webcam footage to the Nginx server. Docker is used to containerize the project’s seven different services into a single composition, ensuring a risk-free deployment
